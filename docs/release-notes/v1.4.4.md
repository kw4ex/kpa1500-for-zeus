# Elecraft KPA1500 for Zeus 1.4.4

The newest version. If you are on 1.1.9 or earlier, everything from 1.1.10 to 1.4.4 is below.

## What's new since 1.1.9
- **Works with a FlexRadio.** *Settings > Radio > My radio is > A FlexRadio* reads the Flex directly, so the amp follows the true VFO on Zeus Link Flex. It follows the Flex that Zeus is connected to, or you pick one of several FlexRadios on the network. It only listens and never changes the radio.
- **"No antenna?" warning** works with a FlexRadio when TCI is on (use the Flex TCI port, normally 40002).
- **Browser page.** The same panel in a web browser at `http://127.0.0.1:8081/`, with a full help page at `/help`. Optionally (off by default) other computers, tablets and phones on your network can use it, with a password (recommended) or without.
- **Built-in help** (the **?** button) and a **small two-line view** (the **⇕** button), remembered for each panel.
- **Buttons to open the browser page** (panel and help) from Settings and from the Help, in your default web browser.
- Number boxes in Settings change only when you type in them (no accidental mouse-wheel changes).
- Lit buttons stay readable when the mouse hovers over them.
- Fixes for Zeus builds that report a stale frequency to plugins.
- Updated PDF guide, help and README.

Full list: [CHANGELOG](https://github.com/kw4ex/zeus-amp/blob/main/CHANGELOG.md).

## How to download (no GitHub account needed)

1. Look at the **Assets** list at the bottom of this release page. If you only see a few files, click **Show all … assets**.
2. Click the file name for **your computer**:

   | Your computer | Click the file ending in |
   | --- | --- |
   | Windows PC | `-<version>.zip` (the one with no extra word, e.g. `…-1.4.4.zip`) |
   | Mac with Apple silicon (M1, M2, M3, M4) | `-osx-arm64.zip` |
   | Intel Mac | `-osx-x64.zip` |
   | Linux PC (64-bit) | `-linux-x64.zip` |
   | Raspberry Pi 4 or 5 (64-bit) | `-linux-arm64.zip` |

3. Your browser saves it, normally in your **Downloads** folder.
4. **Do not click "Source code (zip)" or "Source code (tar.gz)"**. Those are for programmers and Zeus cannot install them.
5. **Do not unzip the file.** Zeus opens the `.zip` itself.
6. In Zeus: **Features > Community > Install local feature**, pick the `.zip`, then restart Zeus.
7. Open the KPA1500 panel. The top line shows the version number.

Not sure which Mac you have? Apple menu > **About This Mac**: "Chip: Apple M…" means Apple silicon; "Processor: Intel" means Intel.

**Other versions:** to go back to an older version, open the [Releases page](https://github.com/kw4ex/zeus-amp/releases), scroll to that version and download the same way. Installing a version replaces the one you have; there is nothing to remove first.

The `KPA1500-for-Zeus-guide.pdf` file in the Assets list is the illustrated "Read Me First" guide.
