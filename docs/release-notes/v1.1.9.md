# Elecraft KPA1500 for Zeus 1.1.9

An earlier version, kept here for anyone who wants it. The newest version is on the [Releases page](https://github.com/kw4ex/zeus-amp/releases/latest).

This version has the telemetry, the controls, the amp following the VFO, Standby on Tune, the "No antenna?" check, Wake-on-LAN and discovery. It does not have the FlexRadio source, the browser page, the small view or the built-in help.

## How to download (no GitHub account needed)

1. Look at the **Assets** list at the bottom of this release page. If you only see a few files, click **Show all … assets**.
2. Click the file name for **your computer**:

   | Your computer | Click the file ending in |
   | --- | --- |
   | Windows PC | `-<version>.zip` (the one with no extra word, e.g. `…-1.1.9.zip`) |
   | Mac with Apple silicon (M1, M2, M3, M4) | `-osx-arm64.zip` |
   | Intel Mac | `-osx-x64.zip` |
   | Linux PC (64-bit) | `-linux-x64.zip` |
   | Raspberry Pi 4 or 5 (64-bit) | `-linux-arm64.zip` |

3. Your browser saves it, normally in your **Downloads** folder.
4. **Do not click "Source code (zip)" or "Source code (tar.gz)"**. Those are for programmers and Zeus cannot install them.
5. **Do not unzip the file.** Zeus opens the `.zip` itself.
6. In Zeus: **Features > Community > Install local feature**, pick the `.zip`, then restart Zeus.
7. Open the KPA1500 panel. The top line shows the version number.

Not sure which Mac you have? Apple menu > **About This Mac**: "Chip: Apple M…" means Apple silicon; "Processor: Intel" means Intel.

**Other versions:** to go back to an older version, open the [Releases page](https://github.com/kw4ex/zeus-amp/releases), scroll to that version and download the same way. Installing a version replaces the one you have; there is nothing to remove first.

The `KPA1500-for-Zeus-guide.pdf` file in the Assets list is the illustrated "Read Me First" guide.
